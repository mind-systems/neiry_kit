# Классификаторы

Классификаторы анализируют EEG-сигнал в реальном времени и выдают смысловые оценки состояния пользователя. Все классификаторы создаются после `device.start()`, иначе плагин бросит исключение.

У классификаторов нет явного `start()` и `stop()`. Они начинают работу сразу после создания, пока устройство стримит данные, и останавливаются вместе с устройством.

## NFB

NFB (Neurofeedback) — базовый классификатор, который вычисляет мощность в пяти ритмических полосах EEG:

| Ритм | Полоса | Смысл |
|------|--------|-------|
| delta | ~1–4 Гц | глубокий сон, восстановление |
| theta | ~4–8 Гц | медитация, дремота |
| alpha | ~8–13 Гц | расслабленное внимание |
| SMR | ~12–15 Гц | спокойная концентрация |
| beta | ~15–30 Гц | активное мышление |

Все значения нормированы в диапазоне 0–1. Поля `delta` и `smr` становятся доступны только после индивидуальной калибровки — без неё они `null`.

```dart
final nfb = NfbClassifier(device);
nfb.stateStream.listen((state) {
  // state.alpha, state.theta, state.beta — double?
});
```

Если заранее есть результаты калибровки, их можно передать при создании:

```dart
final nfb = NfbClassifier(device, calibration: savedData);
```

NFB является базой для классификаторов эмоций и продуктивности — они используют его внутренние вычисления.

## Физиологические состояния

`PhysioClassifier` определяет интегральные состояния: расслабление, усталость, концентрацию, вовлечённость, стресс. Каждое значение — `double?` от 0 до 1. Поле `none` означает, что ни одно состояние не доминирует. Флаги `nfbArtifacts` и `cardioArtifacts` сигнализируют о помехах, которые могли повлиять на оценку.

Классификатор выдаёт результат раз в 2 минуты — это его фиксированный интервал обновления, а не ограничение плагина.

Перед тем как значения станут осмысленными, нужна базовая калибровка. Она занимает несколько минут и собирает индивидуальный профиль пользователя. Без калибровки все поля остаются `null`.

```dart
final physio = PhysioClassifier(device);
await physio.startBaselineCalibration();
physio.calibrationProgress.listen((p) => print('${(p * 100).round()}%'));
await physio.calibrated.first; // завершение калибровки
physio.stateStream.listen((state) { ... });
```

Если у пользователя есть сохранённые данные калибровки с предыдущей сессии, можно загрузить их через `importBaselines(bytes)` и пропустить этап калибровки.

## Эмоции

`EmotionsClassifier` оценивает пять параметров: внимание, расслабление, когнитивную нагрузку, когнитивный контроль и самоконтроль. Все значения `double?`, диапазон 0–1, калибровка не требуется.

Классификатор работает непрерывно и внутренне использует NFB-разложение сигнала — NFB не нужно создавать явно, это происходит автоматически.

```dart
final emotions = EmotionsClassifier(device);
emotions.stateStream.listen((state) {
  // state.attention, state.cognitiveLoad и т.д.
});
```

## Продуктивность

`ProductivityClassifier` — самый многогранный классификатор. Он одновременно ведёт три потока данных:

- `metricsStream` — детальные метрики в реальном времени: усталость, гравитация, концентрация, продуктивность и несколько производных
- `indexesStream` — агрегированные индексы: рекомендация (`RelaxationRecommendation`), стресс (`StressValue`), базовые линии
- `baselineStream` — обновления базовых линий во время калибровки

Поля `productivityScore` и `currentValue` в метриках остаются `null` до завершения калибровки. Остальные метрики начинают поступать сразу.

Дополнительный метод `resetAccumulatedFatigue()` обнуляет накопленную усталость и перезапускает её отсчёт — полезно в начале новой рабочей сессии без перезапуска всего классификатора.

Если есть предварительно вычисленные данные индивидуальной NFB-калибровки, можно передать их при создании — это ускоряет сходимость:

```dart
final productivity = ProductivityClassifier.withCalibration(device, nfbData);
```

## Кардио

`CardioClassifier` анализирует PPG-сигнал (фотоплетизмографию) и вычисляет кардиологические показатели: частоту сердечных сокращений, индекс стресса и индекс Каплана. Поля `stressIndex` и `kaplanIndex` — `double?`, становятся доступны только после набора достаточного количества данных.

Помимо обработанных показателей, `ppgStream` эмитит сырой PPG-сигнал для кастомной аналитики.

```dart
final cardio = CardioClassifier(device);
cardio.stateStream.listen((data) {
  // data.heartRate, data.stressIndex, data.kaplanIndex
  // data.hasArtifacts, data.skinContact, data.metricsAvailable
});
```

Кардио-классификатор опционально принимает данные NFB-калибровки при создании — аналогично продуктивности.

## MEMS

`MEMSClassifier` читает акселерометр и гироскоп устройства и эмитит пакеты сэмплов движения. В отличие от EEG-классификаторов, MEMS не анализирует сигнал мозга — он работает с инерциальными датчиками для определения ориентации и движения головы.

```dart
final mems = MEMSClassifier(device);

mems.memsStream.listen((samples) {
  for (final s in samples) {
    print('accel x=${s.accelerometer.x} y=${s.accelerometer.y} z=${s.accelerometer.z}');
    print('gyro  x=${s.gyroscope.x} y=${s.gyroscope.y} z=${s.gyroscope.z}');
  }
});
```

Каждый элемент стрима — `List<MemsSample>`. SDK накапливает несколько сэмплов между вызовами колбэка и передаёт их пакетом. Все поля всегда заполнены — MEMS не использует сентинельные значения.

Если есть данные NFB-калибровки, можно передать их при создании — это улучшает точность классификатора:

```dart
final mems = MEMSClassifier.withCalibration(device, calibrationData);
```

MEMS-классификатор нужно явно освобождать после использования:

```dart
await mems.dispose();
```
