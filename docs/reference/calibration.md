# Калибровка NFB

Индивидуальная NFB-калибровка определяет персональный профиль альфа-ритма пользователя: пиковую частоту, ширину полосы, мощность и соотношение мощности с открытыми и закрытыми глазами. Эти параметры используют классификаторы NFB, продуктивности и кардио для точной настройки на конкретного человека.

Без калибровки NFB работает с усреднёнными параметрами (альфа ~8–13 Гц), и поля `delta` и `smr` остаются `null`. После калибровки классификатор переключается на индивидуальный диапазон, и все пять ритмов становятся доступны.

## Полная калибровка

Стандартная калибровка состоит из четырёх стадий по 20 секунд каждая:

| Стадия | Глаза | Цель |
|--------|-------|------|
| 1 | Закрыты | Базовая линия альфа в состоянии покоя |
| 2 | Открыты | Измерение подавления альфа при зрительной нагрузке |
| 3 | Закрыты | Подтверждение стабильности базовой линии |
| 4 | Открыты | Подтверждение стабильности подавления |

Итого 80 секунд. SDK анализирует записанный сигнал, находит индивидуальный альфа-пик и вычисляет все параметры.

```dart
NfbCalibrator.calibrateIndividual().listen((event) {
  switch (event) {
    case CalibrationStageFinished(:final stage):
      print('Стадия ${stage.index + 1} завершена');
    case CalibrationCompleted(:final data):
      if (data.isValid) {
        // сохранить data для будущих сессий
      }
  }
});
```

Стрим эмитит `CalibrationStageFinished` после каждой из четырёх стадий, а в конце — `CalibrationCompleted` с результатами. Это sealed класс — компилятор потребует обработать оба варианта.

## Quick mode

Быстрая калибровка — одна стадия 30 секунд с закрытыми глазами. Даёт менее точный результат, но приемлемый для повторной калибровки или когда первая полная калибровка уже была.

```dart
final data = await NfbCalibrator.calibrateIndividualQuick();
```

Первый раз нужно всегда делать полную калибровку — quick mode без полной истории работает хуже.

## Результат калибровки — IndividualNfbData

Объект содержит все вычисленные параметры:

| Поле | Единицы | Типичное значение |
|------|---------|-------------------|
| `individualFrequency` | Гц | 10.0 |
| `lowerFrequency` / `upperFrequency` | Гц | 7.0 / 13.0 |
| `individualBandwidth` | Гц | 6.0 |
| `individualPeakFrequencySuppression` | безразмерный | 2.0 |
| `individualNormalizedPower` | 0–1 | 0.5 |

Поле `isValid` сообщает, прошла ли калибровка успешно. При неудаче `failReason` указывает причину:

- `tooManyArtifacts` — слишком много помех: пользователь двигался, неплотный контакт электродов
- `peakFrequencyAtBorder` — альфа-пик попал на границу диапазона (7 или 13 Гц), редкий случай

Когда `isValid == false`, числовые поля (`individualFrequency`, `individualPeakFrequency`,
`peakPower` и остальные) содержат дефолтные значения SDK, а не реальные данные пользователя.
Передавать такой объект в классификаторы нельзя.

```dart
NfbCalibrator.calibrateIndividual().listen((event) {
  switch (event) {
    case CalibrationStageFinished(:final stage):
      print('Стадия ${stage.index + 1} завершена');
    case CalibrationCompleted(:final data):
      if (!data.isValid) {
        switch (data.failReason) {
          case NfbCalibrationFailReason.tooManyArtifacts:
            // Проверить импеданс, попросить пользователя сесть ровно и не двигаться
            showRetryDialog('Слишком много помех. Проверьте контакт электродов.');
          case NfbCalibrationFailReason.peakFrequencyAtBorder:
            // Редкий физиологический вариант — обычно помогает повторная попытка
            showRetryDialog('Попробуйте ещё раз.');
          case NfbCalibrationFailReason.none:
            break; // не бывает при isValid == false
        }
        return;
      }
      // data.isValid == true — можно сохранять и передавать классификатору
      saveCalibration(data);
  }
});
```

Типичный порядок действий при неудаче:
1. Показать пользователю конкретную причину (не просто «ошибка»).
2. Если `tooManyArtifacts` — предложить проверить импеданс через `device.resistanceStream` перед повторной попыткой.
3. Предложить повторить quick mode или полную калибровку.
4. Если неудачи повторяются — сначала выполнить проверку импеданса и устранить плохой контакт.

## Сохранение и загрузка

Результат калибровки стоит сохранять между сессиями. `IndividualNfbData.toMap()` сериализует объект в `Map<String, dynamic>`, который можно хранить в JSON или локальной базе данных. При следующем запуске данные восстанавливаются через `fromMap` и передаются классификатору.

```dart
// Сохранение
final json = jsonEncode(data.toMap());
prefs.setString('nfb_calibration', json);

// Загрузка
final map = jsonDecode(prefs.getString('nfb_calibration')!);
final data = IndividualNfbData.fromMap(map);
final nfb = NfbClassifier(device, calibration: data);
```

Для физиологических состояний и продуктивности механизм аналогичный, но там сохраняется непрозрачный `Uint8List` — плагин не интерпретирует его содержимое, только сохраняет и передаёт обратно.

## Практические советы

Перед калибровкой стоит убедиться, что импеданс всех каналов в норме через `device.resistanceStream`. Если хотя бы один электрод не касается кожи, калибровка, скорее всего, завершится с `tooManyArtifacts`. Во время калибровки пользователю нужно сидеть неподвижно — движения и жевание генерируют миографические артефакты.

На iOS рекомендуется отключить блокировку экрана на время калибровки через `UIApplication.shared.isIdleTimerDisabled = true` — 80 секунд это немного, но экран может заблокироваться.
