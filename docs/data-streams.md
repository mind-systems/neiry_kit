# Потоки данных

Все данные с устройства приходят через Dart `Stream`. Стримы — broadcast: можно подписываться из нескольких мест одновременно. Данные начинают поступать только после вызова `device.start()` — до этого стримы не эмитят ничего.

Рекомендуется подписываться на стримы **до** вызова `start()`, чтобы не пропустить первые пакеты.

## EEG

`device.eegStream` эмитит сырые EEG-данные с устройства. Каждый пакет содержит несколько сэмплов сразу — обычно 4–8 за пакет — по всем каналам. Структура пакета:

- `rawValues` — необработанный сигнал в микровольтах, индексируется `[канал][сэмпл]`
- `processedValues` — сигнал после фильтрации артефактов, тоже `[канал][сэмпл]`; в режиме `Resistance` не заполняется
- `channelCount` и `sampleCount` — размерность массивов
- `timestamp` — метка первого сэмпла в пакете

Частота дискретизации устройства-специфична, типично 250 Гц. Реальное значение доступно через `device.getEEGSampleRate()` после подключения.

## PSD

`device.psdStream` эмитит частотный анализ сигнала. PSD (Power Spectral Density) показывает распределение мощности по частотным полосам. В пакете приходят:

- `frequencies` — список частот в Гц
- `psd` — мощность для каждого канала и каждой частоты, `[канал][частота]`
- `frequencyResolution` — шаг между частотными бинами
- `bands` — предрассчитанные диапазоны дельта, тета, альфа, SMR, бета, если устройство их поддерживает

PSD доступен только в режиме `Signal`.

## Артефакты

`device.artifactsStream` эмитит информацию о том, в каких каналах обнаружены артефакты — миографические помехи, движение, моргание. Для каждого канала приходит флаг наличия артефакта и числовая метрика качества сигнала от 0 до 1.

SDK автоматически исключает артефактные сэмплы из `processedValues` в `eegStream`. Стрим артефактов нужен для отображения качества сигнала в UI.

## Сопротивление электродов

`device.resistanceStream` доступен в режимах `Resistance` и `SignalAndResist`. Для каждого канала приходит его название и сопротивление в кОм. Хорошим контактом считается значение ниже 500 кОм. Измерения приходят по каналам по очереди, не одновременно.

Сопротивление используется для проверки качества надевания гарнитуры перед началом сессии — если электрод не касается кожи, значение будет очень высоким.

## Батарея

`device.batteryStream` эмитит целое число от 0 до 100 при каждом изменении уровня заряда. Для устройств без батареи стрим может не эмитить ничего. Текущее значение кэшируется и доступно синхронно через `device.battery`.

## Сентинельные значения

Все поля классификаторов и некоторые поля стримов используют `-1` / `-1.0` как «данных пока нет». Dart API конвертирует их в `null` на уровне кодека — в Dart-коде явная проверка на `-1` нигде не нужна. Поля, которые могут быть `null`, объявлены как `double?` или `int?`.
