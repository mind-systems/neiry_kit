# Обзор neiry_kit

neiry_kit — Flutter-плагин для работы с нейрогарнитурами Neiry. Плагин берёт на себя Bluetooth-поиск, подключение и взаимодействие с нативным SDK — приложение работает только с Dart API, нативный слой скрыт.

## Что измеряет кит

Кит даёт два класса данных: **сырые сигналы** с сенсоров устройства и **смысловые состояния** из классификаторов, которые интерпретируют сигналы в реальном времени.

### Сырые сигналы устройства

| Сигнал | Что измеряет |
|---|---|
| EEG | Электрическую активность мозга по всем каналам в микровольтах — сырой и фильтрованный сигнал |
| PSD | Распределение мощности сигнала по частотным полосам (дельта, тета, альфа, SMR, бета) |
| PPG | Фотоплетизмографию — пульсовую волну с оптического сенсора |
| Сопротивление | Качество контакта каждого электрода с кожей, в кОм — для проверки перед сессией |
| Батарея | Уровень заряда в процентах |

Подробно о форматах, частотах дискретизации и сентинельных значениях — в [потоках данных](reference/data-streams.md).

### Классификаторы

Классификаторы анализируют EEG и PPG в реальном времени и выдают нормированные оценки 0–1. Поле остаётся `null`, пока не накоплено достаточно данных.

| Классификатор | Что даёт | Нужна калибровка |
|---|---|---|
| NFB | Мощность ритмов: дельта, тета, альфа, SMR, бета | Нет; с индивидуальной калибровкой дельта и SMR становятся точнее |
| Эмоции | Внимание, расслабление, когнитивная нагрузка, когнитивный контроль, самоконтроль | Нет |
| Физиологические состояния | Расслабление, усталость, концентрация, вовлечённость, стресс — обновление раз в 2 минуты | Да — базовая, несколько минут |
| Продуктивность | Усталость, концентрация, продуктивность — детальные метрики и агрегированные индексы | Нет; точнее с базовой и индивидуальной калибровкой |
| Кардио | ЧСС, индекс стресса, индекс Каплана — из PPG-сигнала | Нет |
| MEMS | Акселерометр и гироскоп — ориентация и движение головы | Нет |

Описание каждого классификатора, их стримов и особенностей — в [классификаторах](reference/classifiers.md).

## Сценарий сессии

Порядок вызовов строгий — каждый шаг зависит от предыдущего:

1. **Разрешения** — запросить BLE-разрешения (Android) до любого вызова SDK
2. **Поиск** — `DeviceLocator().requestDevices(...)` возвращает список найденных гарнитур
3. **Подключение** — `locator.createDevice(serial)` → `device.connect()`
4. **Создать классификаторы** — после `connect()`, до `start()`
5. **Подписаться на стримы** — до `start()`, чтобы не пропустить первые пакеты
6. **Запустить стриминг** — `device.start()`, после этого данные начинают поступать
7. **Завершить** — `device.stop()` → `device.disconnect()` → `device.dispose()`

Полный разбор с примерами кода — в [сценарии сессии](guides/session-guide.md).
