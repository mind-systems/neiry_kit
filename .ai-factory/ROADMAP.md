# Project Roadmap

> Flutter plugin that wraps the Neiry Capsule C SDK — exposes a clean Dart API for BCI device lifecycle, EEG streaming, and all classifiers to mind_mobile.

## Milestones

- [x] **Plugin scaffold** — Flutter plugin boilerplate, pubspec, iOS/Android build configs
- [x] **Dart channel contract** — create `lib/src/channel_names.dart` and export it from `lib/neiry_kit.dart`. File contains: `NeiryChannels` (8 MethodChannel IDs), `NeiryEvents` (28 EventChannel IDs), `DeviceLocatorMethods` / `DeviceMethods` / `ClassifierMethods` / `NFBCalibratorMethods` (all method name strings), `NeiryArgs` (9 argument key strings), `NeiryDeviceType` / `NeiryDeviceMode` / `NeiryConnectionState` enums with int mappings. Add unit tests verifying all strings are unique and enum int values match SDK. Full spec: [`.ai-factory/notes/01-channel-contract.md`](.ai-factory/notes/01-channel-contract.md)
