# Project Roadmap

> Flutter plugin that wraps the Neiry Capsule C SDK — exposes a clean Dart API for BCI device lifecycle, EEG streaming, and all classifiers to mind_mobile.

## Milestones

- [x] **Plugin scaffold** — Flutter plugin boilerplate, pubspec, iOS/Android build configs
- [x] **Dart channel contract** — create `lib/src/channel_names.dart` and export it from `lib/neiry_kit.dart`. File contains: `NeiryChannels` (8 MethodChannel IDs), `NeiryEvents` (28 EventChannel IDs), `DeviceLocatorMethods` / `DeviceMethods` / `ClassifierMethods` / `NFBCalibratorMethods` (all method name strings), `NeiryArgs` (9 argument key strings), `NeiryDeviceType` / `NeiryDeviceMode` / `NeiryConnectionState` enums with int mappings. Add unit tests verifying all strings are unique and enum int values match SDK. Full spec: [`.ai-factory/notes/01-channel-contract.md`](.ai-factory/notes/01-channel-contract.md)
- **Dart models**
  - [x] **sentinel helper + exceptions** — `lib/src/models/internal/sentinel.dart` with `orNull(double?)`, `lib/src/models/neiry_exception.dart` with `NeiryException` base + `BluetoothDisabledException` / `DeviceNotConnectedException` / `CalibrationRequiredException`; `NeiryErrorCode` enum (16 values). Spec: [`.ai-factory/notes/02-dart-models.md`](.ai-factory/notes/02-dart-models.md)
  - [x] **scalar + signal models** — `DeviceInfo` (no nulls), `NeiryError` (for exception construction), `NfbUserState` / `PhysiologicalStatesValue` / `EmotionsStates` (all use `orNull` sentinel pattern on float fields). Spec: [`.ai-factory/notes/02-dart-models.md`](.ai-factory/notes/02-dart-models.md)
  - [x] **productivity models** — `ProductivityMetrics` (11 nullable floats + `Uint8List?` artifacts, `fatigueGrowthRate` int enum), `ProductivityIndexes` (6 nullable floats + `relaxation`/`stress` int enums + `hasArtifacts` bool), `ProductivityBaselines` (6 nullable floats). Spec: [`.ai-factory/notes/02-dart-models.md`](.ai-factory/notes/02-dart-models.md)
  - [x] **calibration models** — `IndividualNfbData` (all non-nullable, defaults from spec), `CalibrationStage` enum, `CalibrationFailReason` enum; `CalibrationEvent` sealed class with subtypes `CalibrationStageFinished(stage)` and `CalibrationCompleted(data)` — native sends `{'type':'stage'/'done'}` over one EventChannel, Dart deserializes to correct subtype; only `IndividualNfbData` has `fromMap`. Spec: [`.ai-factory/notes/02-dart-models.md`](.ai-factory/notes/02-dart-models.md)
  - [x] **export + unit tests** — export all models from `lib/neiry_kit.dart`; tests cover sentinel→null, `Uint8List?` size=0 case, enum int mappings, `CalibrationEvent` dispatch by `type` key, `IndividualNfbData.fromMap` round-trip. Spec: [`.ai-factory/notes/02-dart-models.md`](.ai-factory/notes/02-dart-models.md)
- **Dart API**
  - [ ] **DeviceLocator** — singleton factory with optional `logDirectory`; `requestDevices({type, searchTime})` returns `Stream<List<DeviceInfo>>` that emits once then completes; `createDevice(serial)`, `update()` (single-threaded mode), `dispose()`. Spec: [`.ai-factory/notes/03-dart-api-device.md`](.ai-factory/notes/03-dart-api-device.md)
  - [ ] **Device** — lifecycle (`connect/disconnect/start/stop`); state streams (`connectionStateStream`, `modeChangedStream`); data streams (`eegStream`, `psdStream`, `artifactsStream`, `resistanceStream`, `batteryStream`, `errorStream`); getters (`getInfo`, `battery`, `mode`, `getEEGSampleRate`, `getPPGSampleRate`, `getMEMSSampleRate`, `getPPGIrAmplitude`, `getPPGRedAmplitude`, `getChannelNames`, `getChannelIndex`); enforces state machine invariants (`start()` before classifiers, `connect()` before `start()`). Spec: [`.ai-factory/notes/03-dart-api-device.md`](.ai-factory/notes/03-dart-api-device.md)
  - [ ] **NfbClassifier** — `factory NfbClassifier(Device, {IndividualNfbData?})`; streams: `stateStream`, `errorStream`. Spec: [`.ai-factory/notes/04-dart-api-classifiers.md`](.ai-factory/notes/04-dart-api-classifiers.md)
  - [ ] **PhysioClassifier** — `factory PhysioClassifier(Device)`; `startBaselineCalibration()`, `importBaselines(Uint8List)`; streams: `stateStream`, `calibrationProgress`, `calibrated`, `individualNfbStream`. Spec: [`.ai-factory/notes/04-dart-api-classifiers.md`](.ai-factory/notes/04-dart-api-classifiers.md)
  - [ ] **EmotionsClassifier** — `factory EmotionsClassifier(Device)`; streams: `stateStream`, `errorStream`; no calibration required. Spec: [`.ai-factory/notes/04-dart-api-classifiers.md`](.ai-factory/notes/04-dart-api-classifiers.md)
  - [ ] **ProductivityClassifier** — two factory paths (`ProductivityClassifier(Device)`, `ProductivityClassifier.withCalibration(Device, IndividualNfbData)`); `startBaselineCalibration()`, `importBaselines()`, `resetAccumulatedFatigue()`; streams: `baselineStream`, `indexesStream`, `metricsStream`, `calibrationProgress`, `calibrated`, `individualNfbStream`. Spec: [`.ai-factory/notes/04-dart-api-classifiers.md`](.ai-factory/notes/04-dart-api-classifiers.md)
  - [ ] **CardioClassifier** — two factory paths (`CardioClassifier(Device)`, `CardioClassifier.withCalibration(Device, IndividualNfbData)`); streams: `stateStream` (`CardioData`: heartRate, stressIndex, kaplanIndex, quality flags), `ppgStream`, `errorStream`; pure C API (`clCCardio_*`). Spec: [`.ai-factory/notes/04-dart-api-classifiers.md`](.ai-factory/notes/04-dart-api-classifiers.md)
  - [ ] **NfbCalibrator** — static class; `calibrateIndividual()` → `Stream<CalibrationEvent>`; `calibrateIndividualQuick()` → `Future<IndividualNfbData>`; `importCalibrationData()`, `getCalibrationData()`, `isCalibrated()`. Spec: [`.ai-factory/notes/05-nfb-calibration.md`](.ai-factory/notes/05-nfb-calibration.md)
  - [ ] **export + integration tests** — export all classes; tests: state machine throws on wrong order, stream types match models, `CalibrationEvent` sealed dispatch
